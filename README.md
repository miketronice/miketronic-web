# Miketronic Web

Web oficial de **Miketronic**, portfolio profesional centrado en electrónica automotriz, diagnosis, programación, reparación de módulos, cerrajería y tecnología aplicada al automóvil.

🌐 **Web:** https://miketronic.es/

## Estado del proyecto

**Versión final publicada y operativa.**

La web está desplegada mediante **GitHub Pages** y utiliza `miketronic.es` como dominio personalizado. La página principal y la sección de servicios están preparadas para indexación en buscadores, con metadatos SEO, sitemap, robots.txt, datos estructurados y recursos sociales configurados.

## Secciones principales

- **Inicio** — presentación de Miketronic y acceso a las principales áreas de la web.
- **Sobre mí** — experiencia, especialización y enfoque profesional.
- **Especialidades** — diagnosis y programación, reparación de módulos, cerrajería, multimedia, asistencia remota y contenido técnico.
- **Proyectos** — Electromecánikos y MT Manager.
- **Últimos contenidos** — trabajos recientes, YouTube y contenido técnico.
- **Contacto y redes sociales** — acceso directo a los canales oficiales de Miketronic.
- **Servicios** — página dedicada en https://miketronic.es/servicios/ con información ampliada sobre los servicios de electrónica automotriz.

## Características

- Diseño responsive para escritorio y móvil.
- Estética oscura y tecnológica propia de Miketronic.
- Animación técnica de diagnosis y comunicación OBD en la portada.
- Galerías y carruseles de trabajos e imágenes.
- Iconos SVG locales y carga optimizada de recursos.
- Imágenes WebP optimizadas.
- SEO técnico con canonical, Open Graph, Twitter Cards y Schema.org.
- `sitemap.xml` y `robots.txt` configurados.
- Favicon e identidad visual para navegador y resultados de búsqueda.
- Integración con GitHub Pages y dominio personalizado.

`servicios.html` se mantiene únicamente como compatibilidad y redirige a la URL canónica `/servicios/`.

## Tecnologías

Proyecto estático desarrollado con **HTML5, CSS3 y JavaScript**, sin frameworks ni dependencias pesadas. El objetivo es mantener una web rápida, sencilla de mantener y optimizada para GitHub Pages.
